# 책갈피 — 대전 책 정리

개인용 책장과 종이책 정리 결정을 위한 로컬 우선 PWA입니다. 책 정보는 브라우저 `localStorage`에만 저장되며 서버로 전송하지 않습니다. ISBN 자동 조회 시에만 Open Library 공개 API를 호출합니다.

## 주요 기능

- ISBN 직접 입력 및 지원 브라우저에서 카메라 바코드 촬영
- Open Library ISBN 메타데이터 조회
- 애장본·필기·희귀본·업무 참고·재독 가능성에 따른 정리 결정 자동 추천
- 실물 보관·자가 스캔·밀리 대체·판매·기증·폐기 상태 관리
- 내 책장 검색, 필터, 수정, 삭제, 박스 위치 기록
- JSON 백업·복원 및 CSV 내보내기
- PWA 설치와 오프라인 실행
- 밀리의 서재 본문 추출이나 DRM 우회 기능은 포함하지 않음

## Windows에서 실행

1. 폴더 안의 `start-windows.bat`을 더블클릭합니다.
2. 브라우저에서 `http://localhost:4173`이 열립니다.
3. 종료할 때 검은 명령창에서 `Ctrl+C`를 누릅니다.

Python이 설치돼 있어야 합니다. 카메라 바코드 기능은 Chrome 계열 브라우저의 지원 여부와 카메라 권한에 따라 사용할 수 있습니다. 지원되지 않으면 ISBN을 직접 입력할 수 있습니다.

## 개발 및 검증

```bash
npm test
npm run serve
```

현재 자동 테스트는 결정 추천, ISBN 정규화, CSV 이스케이프, 책 추가·수정·삭제·검색, 집에서 내보낼 책 집계, 필수 UI 및 PWA 연결을 검사합니다.
